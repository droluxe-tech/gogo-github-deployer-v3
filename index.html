Cara dapetin token

1. Buka github.com/settings/tokens/new (token classic)
2. Expiration: pilih 90 days
3. Centang scope repo dan delete_repo
4. Generate token, copy, paste di bawah
Token disimpen di localStorage browser lu aja. Token cuma dikirim ke api.github.com.
